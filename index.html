GitHub Actions runners

Cut your CI bill and build times with one line.

Bare-metal Linux (AMD EPYC) and Apple Silicon macOS runners for GitHub Actions. Change runs-on — or let the Migration Wizard open the pull request — and your jobs run on fresh, disposable VMs.

  • Linux x64, and macOS on Apple Silicon (M4 Pro)
  • Dependency caching built in; actions/cache keeps working
  • Every job on a fresh VM, so nothing carries between runs
